Data stored by the app

The app stores usernames, bcrypt password hashes, audit logs, uploaded log content and events in SQLite, with session records stored by the SQLite session store and a session identifier held in the browser cookie. The app also stores alerts, incidents, and related operational records. A deployment operator controls the database location and backups. The project documentation does not specify a retention period.

AbuseIPDB

If an operator configures an AbuseIPDB API key, public source IP addresses may be sent to AbuseIPDB for reputation lookups. Lookups are cached for one hour. If no key is configured, the app uses a local list. The operator should review AbuseIPDB's terms and privacy practices.

Optional AI provider

If an AI provider is enabled, alert text and related event details may be sent to the configured provider for analysis. The documented providers are Gemini, OpenAI, and Ollama. The provider receives text only; the AI layer does not run SQL. AI is disabled unless configured.

Browser preview

The marketing site's interactive preview parses text in your browser and does not upload it. Loading the bundled sample reads a local static file from this site.
