A simple processing path

From a line of text to an alert.

Each event moves through the same pipeline, whether it comes from a log upload or the synthetic demo simulator.

01 · SOURCELog source

Linux auth.log, Apache/Nginx access logs, CSV, or synthetic simulator event.

02 · PARSEParser

Format-specific fields become a normalized event with timestamp and source details.

03 · DETECTDetection engine

Ten enabled rules check thresholds, event types, and statistical IP volume.

04 · SCORERisk engine

Severity sets the base score. Repetition and malicious reputation may add points.

05 · REVIEWAlert

MITRE mapping, related logs, risk explanation, and alert to incident workflow.

Historical replay

Event time drives windows.

Threshold checks look around the timestamp of the event being processed. That means an old log file can still be evaluated as a coherent sequence instead of being compared against the current clock.
